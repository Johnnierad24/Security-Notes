# security-notes

My cybersecurity learning journey: notes, scripts, CTF write-ups and projects, from beginner to job-ready.

I am a BSc Information Technology student in Kenya following a structured 24-week plan (Linux, networking, Python and Bash, SQL, recon, OSINT, Windows, wireless, web, API, mobile, cloud, threat intelligence and GRC). I practise in my own isolated lab (Kali Linux in VirtualBox) and on legal learning platforms.

## Ethics and rules

Everything in this repository was done on systems I own or on platforms built for learning. Read my [Personal Code of Conduct](code-of-conduct.md).

**No flags, passwords, private data or live exploits are published here.**
